# @stewarthaines/seed-html → seed-html

This package is a compatibility alias. SEED.html — the Simple EPUB Editor — is published as [`seed-html`](https://www.npmjs.com/package/seed-html):

```
npx seed-html
```

Running `npx @stewarthaines/seed-html` still works: it installs the latest `seed-html` and launches it, passing all arguments through. New releases ship under `seed-html` only.
